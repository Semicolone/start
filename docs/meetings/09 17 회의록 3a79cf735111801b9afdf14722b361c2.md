**🔗 기능 개요**

저장된 인사이트 중 새로 저장하는 질문과 의미적으로 유사한 것을 자동으로 찾아서 연결해주는 기능이에요.

예를 들어 "면접 준비 어떻게 해야 해?"를 저장하면, 이전에 저장했던 "취업 준비 로드맵", "포트폴리오 구성 방법" 같은 인사이트를 자동으로 추천해줘요.

파편화된 지식들을 연결해서 사용자가 자신의 지식을 네트워크처럼 쌓아갈 수 있게 하는 게 목표예요.

---

**💡 기획 의도**

저희 앱의 핵심 목표가 "인사이트를 내 지식으로 내재화"잖아요. 근데 지금은 저장만 하고 끝나는 구조라 사용자가 다시 꺼내보기가 어렵거든요.

연결짓기는 새 질문을 저장하는 순간 관련된 과거 인사이트를 자동으로 보여줘서, 사용자가 자연스럽게 이전 지식을 다시 떠올리게 만들어요. 능동적으로 연결하는 과정 자체가 내재화를 만들어요.

---

**🛠 구현 방식 (2가지 옵션)**

**옵션 1 — 키워드 매칭 (추천 👍)**

Groq API가 이미 인사이트마다 키워드 5개를 뽑아주고 있잖아요. 이 키워드가 겹치는 인사이트를 PostgreSQL 쿼리로 찾아서 추천하는 방식이에요.

- 추가 기술 스택 없음
- 추가 API 비용 없음
- 구현 시간 1~2일
- 단점: 키워드가 다르면 의미가 비슷해도 못 찾음

**옵션 2 — 임베딩 기반 의미 검색**

텍스트를 벡터로 변환해서 의미적으로 유사한 인사이트를 찾는 방식이에요. "면접"이랑 "취업 준비"처럼 키워드가 달라도 연관 인사이트를 찾을 수 있어요.

- pgvector (PostgreSQL 익스텐션) 추가 필요
- 임베딩 API 비용 소량 발생
- 구현 시간 3~5일
- 정확도가 훨씬 높음

---

**📌 제안하는 순서**

일단 옵션 1로 먼저 붙이고, 데이터가 쌓이면 옵션 2로 업그레이드하는 게 좋을 것 같아요.

연결짓기는 인사이트가 최소 30~50개는 쌓여야 의미가 있어서, 초기엔 어떤 방식이든 추천할 게 많지 않거든요. 옵션 1은 지금 FastAPI에 엔드포인트 하나 추가하는 수준이라 빠르게 붙일 수 있어요.

### 1. 연관 인사이트 자동 연결

새로운 질문을 저장했을 때, 기존에 저장된 인사이트 중 키워드나 의미가 비슷한 인사이트를 자동으로 추천해주는 기능입니다. 예를 들어 “면접 준비 어떻게 해야 해?”를 저장하면, 이전에 저장한 “취업 준비 로드맵”, “포트폴리오 구성 방법” 같은 인사이트를 함께 보여줍니다. 이를 통해 사용자는 새 질문을 저장하는 순간 과거의 관련 지식을 다시 떠올릴 수 있고, 파편화된 AI 답변들이 하나의 지식 흐름으로 연결됩니다.

구현은 우선 Groq API가 이미 생성한 키워드 5개를 활용해 키워드 매칭 방식으로 시작하는 것이 현실적입니다. 추가 API 비용이나 기술 스택 없이 FastAPI 엔드포인트를 추가하는 수준으로 구현할 수 있고, 이후 데이터가 충분히 쌓이면 pgvector 기반 임베딩 검색으로 고도화할 수 있습니다.

UI는 인사이트 저장 완료 화면 하단의 “이런 인사이트도 있어요” 또는 인사이트 상세 페이지 하단의 “연관 인사이트” 카드 형태가 자연스러울 것 같습니다.

---

### 2. 질문 흐름 타임라인

비슷한 키워드나 카테고리로 연결된 인사이트들을 시간순으로 보여주는 기능입니다. 예를 들어 “백엔드 취업 준비”라는 흐름 안에서 처음에는 “백엔드 공부 뭐부터 해?”처럼 넓은 질문을 했다가, 이후 “포트폴리오 구성”, “JWT 로그인 구현”, “기술면접 준비”처럼 질문이 점점 구체화되는 과정을 보여줄 수 있습니다.

이 기능은 사용자가 단순히 질문을 저장한 것이 아니라, 자신의 사고와 관심사가 어떻게 발전했는지 확인하게 해줍니다. 즉, FLOW가 “질문 목록 저장 앱”이 아니라 “내 질문이 쌓이고 발전하는 지식 흐름을 보여주는 앱”이라는 느낌을 줄 수 있습니다.

초기 구현은 같은 카테고리나 겹치는 키워드가 많은 인사이트를 시간순으로 나열하는 방식으로 충분하고, 이후에는 AI가 “처음에는 진로 탐색 중심이었고, 최근에는 실제 구현 질문으로 구체화되었어요” 같은 해석 문장을 생성하도록 확장할 수 있습니다.

---

### 3. 다시 볼 인사이트 큐

저장한 인사이트가 그대로 방치되지 않도록, 일정 시간이 지난 인사이트를 다시 추천해주는 기능입니다. 예를 들어 “3일 전에 저장한 ‘백엔드 취업 준비 로드맵’을 다시 확인해보세요”처럼 홈 화면이나 리포트 화면에 노출할 수 있습니다.

이 기능은 FLOW의 핵심 목표인 “AI 답변을 내 지식으로 내재화”하는 데 직접적으로 연결됩니다. 단순히 저장하는 것이 아니라, 적절한 시점에 다시 보게 만들어 복습과 회고를 유도하기 때문입니다.

처음에는 복잡한 알고리즘 없이 저장 후 3일, 7일, 14일이 지난 인사이트 중 최근 반복 키워드와 관련 있는 항목을 추천하는 방식으로 구현할 수 있습니다. 개발 볼륨은 크지 않으면서도 사용자가 앱에 다시 들어올 이유를 만들어줄 수 있습니다.

---

### 4. 내 말로 정리하기

인사이트 상세 페이지에서 사용자가 AI 답변을 자신의 말로 한 줄 정리할 수 있게 하는 기능입니다. 예를 들어 AI 답변을 읽은 뒤 “백엔드 취업 준비는 CS, 프로젝트, API 경험, 면접 대비를 함께 준비해야 한다”처럼 직접 정리하게 하는 방식입니다.

AI 답변을 그대로 저장하는 것만으로는 내 지식이 되기 어렵기 때문에, 사용자가 자신의 언어로 다시 표현하는 과정이 필요합니다. 이 기능은 개발 볼륨도 비교적 작고, `user_note` 또는 `insight_notes` 테이블을 추가하는 방식으로 구현할 수 있습니다.

결과적으로 FLOW는 저장된 인사이트를 단순히 보관하는 것이 아니라, 사용자가 다시 보고, 연결하고, 자기 언어로 정리하면서 실제 지식으로 내재화하도록 돕는 서비스가 될 수 있습니다.
